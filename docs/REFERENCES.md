# CourseCraft AI — References & Citations

All research, technologies, methods and standards used in the project, written in **IEEE citation style** for the project report and paper. BibTeX entries for LaTeX are in [references.bib](references.bib); the keys are given in brackets.

**How to maintain this file**

- When a PR adopts a new technology, method or paper, add it here in the same PR. Give it the next `R` number, and say where it is used.
- **Status:** ✅ used in the codebase · 🧭 design/method basis (cited in SPEC/decisions) · ⏳ planned (becomes ✅ when its issue merges).
- Web sources carry an access date. Update it when you re-check a page.
- Entries marked **⚠ verify** were copied from the original report and need their details checked against the actual paper before submission.
